Indonesia Emas — Twitter/X Public Discourse Dataset

This project compiles a dataset of public conversations on Twitter/X related to Indonesia Emas 2045, covering themes such as national development, digital transformation, education, economic outlook, and youth participation in shaping Indonesia’s future.

A. Project Purpose

The aim of this project is to build a raw text dataset sourced from Twitter/X to support research tasks such as:

1. Public opinion analysis
2. Topic identification and trend discovery
3. Policy research
4. NLP and machine learning experiments
5. Long-term discourse studies related to Indonesia Emas

B. Key Features

1. Scrapes tweets containing keywords and hashtags such as: #IndonesiaEmas
2. Extracts essential components: 
   a. Includes a Jupyter Notebook outlining the scraping workflow
   b. Outputs a clean .txt dataset ready for analysis

C. Repository Structure

├── indonesia_emas.txt               # Raw text dataset

└── README.md                        # Project documentation

D. Possible Extensions

Potential research extensions include:

1. Sentiment analysis using classical or transformer-based models
2. Topic modeling (LDA, NMF, BERTopic)
3. Social network analysis (SNA) to identify prominent actors
4. Temporal trend visualization
5. Building an interactive dashboard (Streamlit or Plotly Dash)
6. Discourse and framing analysis related to Indonesia’s long-term vision
